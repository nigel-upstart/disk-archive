# Sanitized Python reference (temporary)

Owner: disk-archive maintainers · Status: reference only · Updated: 2026-11-25

This is an allowlisted copy of the legacy Python source and its redactor test,
not a supported archiver. No runtime data, dependency environment, lockfile,
production README, state database, logs, bundles, or session contents were copied.
It supports parity testing while Rust is developed to replace the Python archiver.
Python is the fallback during that transition, but this sanitized copy cannot be
used as the fallback: its CLI is disabled and it has no runtime configuration.
Remove this directory once the Rust port proves parity.

## Intentional deviations

`config.py` replaces all destination/profile/region defaults with empty strings,
all discovery roots with empty tuples, and home/work paths with synthetic anchors.
`__init__.py` no longer imports the CLI, so redactor-only tests require neither
boto3 nor truststore. `cli.main()` is disabled with an unconditional error before
loading pipeline/upload dependencies. The
redactor, scanner, discovery, uploader, state, and pipeline logic are otherwise
unchanged. No package metadata or executable entry point is installed.

Do not invoke the pipeline or uploader. They remain destructive reference code.
Legacy `--dry-run` still redacts in place, key construction strips leading dots,
and legacy HEAD verification is weaker than the Rust contract. These are known
behaviors to replace, not safety guarantees to preserve. Line-by-line processing
also does not bound memory for an arbitrarily long line; the Rust port must enforce
its own chunk and match limits.

## Synthetic goldens

`fixtures/redactor/cases.json` defines invented inputs, finding values, and
1-based line-drop requests. None are real credentials or sampled session logs.
`expected.json` was generated by the unchanged copied redactor, not hand-written.
It pins output bytes (hex) and replacement counts. The runner sets fixed synthetic
timestamps, supplies a deterministic source stat, spies on the real `os.utime` call
to verify restoration at legacy float-second precision, and checks resulting mtime
before reading output. It does not assert a later atime observation: host indexers
can read temporary files and change atime immediately after restoration. All
redaction happens in a temporary directory.

```sh
python3 legacy/python/tests/golden.py --check
# Deliberate regeneration only; review the expected.json diff:
python3 legacy/python/tests/golden.py --write
# Optional, isolated pytest run (never uses the production environment):
PYTHONPATH=legacy/python/src uv run --no-project --with pytest python -m pytest legacy/python/tests
```

Python 3.12+ is required; validated with Python 3.14. Goldens cover finding/raw_v2
replacement, JSON escapes, longest-first overlaps, multiline pieces and their
12-character cutoff, env assignments, inline/multiline/unterminated PEM, dropped
lines, empty input, non-UTF8 bytes, and no-final-newline preservation. These are
redactor goldens only: scanner recall, re-scan blocking, upload verification, and
delete safety require independent Rust pipeline tests.
